# weather

杭州天气，两个用途：

1. **被动查**：`weather` 工具，有人问天气时实时查 open-meteo。
2. **主动提**：每天按 `check_times` 看两次预报，只有降雨、高温、低温、大风、骤降温这类不寻常的天气，才作为一条场景事件交给对话。由 Bot 自己决定要不要在聊天里提、怎么提。

不会直接发消息，正常天气什么都不做。

## 数据

open-meteo 免费接口，不需要 key。默认坐标杭州（30.2741, 120.1551），可在插件设置里改。

## 去重

同一件事每天只说一次（KV 记录 `sent`），检查过的时刻也落盘（`checked`），重启不会重复。
