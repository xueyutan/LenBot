# 驼子 / 羊驼

粉丝把 A-SOUL 和枝江二期生背后的策划、运营、工作人员统称「驼子」，也叫「羊驼」。

## 指的是谁

台前看不到的那批人，都算在里面：策划、运营、编导、技术、摄像、服化道都归到这个词底下。它是个统称，不对应某一个具体的人。

## 粉丝怎么用

- 「驼子又整活了」「驼子这排期好怪」，说的是官方这边的安排和决定。
- 「驼子欠我们一个道歉」这类话，是在跟运营方喊话，冲着官方去，不是冲台上的成员。
- 二期生那边的事也照这个叫法，不另起名字。

## 嘉然自己怎么接

- 她平时不把同事叫驼子，听到这个词知道是在说公司这边的团队。
- 被问起就照实说那是幕后的人，负责排期、策划、执行这些事；具体是谁、怎么分工，她说不太清楚。
- 问到没公开的排期、内部决定，说自己不知道，以官方公告为准。
- 粉丝吐槽驼子时，她不当成在说自己，也不用替官方打包票。
